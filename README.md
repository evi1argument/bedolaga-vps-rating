## Как работает рейтинг

**Score** = сумма положительных реакций − сумма отрицательных реакций на всех тестах бренда.

| Положительные | Отрицательные |
|:---:|:---:|
| 👍 🔥 ❤️ ❤️‍🔥 💯 😍 🫡 🤝 👌 🏆 💪 🎉 ✅ 🌟 👏 | 👎 💩 🤡 😡 🤮 💀 🖕 😞 🤨 🥴 |

Каждый тест учитывается **один раз**. Повторные посты одного пользователя получают реакции от аудитории — это и есть «голос сообщества».
